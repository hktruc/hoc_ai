AI Agent Architecture
Từ nền tảng đến thực chiến

Học cách nhìn một quy trình thực tế, phân rã công việc, quyết định phần nào dùng code — phần nào dùng AI — phần nào cần agent tự quyết định, rồi thiết kế kiến trúc hệ thống hoàn chỉnh.

MỤC TIÊU

Không học framework trước. Học tư duy kiến trúc trước.

Đích đến không phải là “biết dùng LangChain” hay “biết gọi một API”. Đích đến là có khả năng tự thiết kế một AI Agent chạy local, dùng API, có workflow rõ ràng, phục vụ một mục đích chuyên biệt.

NGUYÊN TẮC XUYÊN SUỐT

Luôn tư duy theo thứ tự này

Business Problem→Work Process→Task Decomposition→Deterministic / AI→Workflow→Tools→Context→State→Agent Loop→Evaluation→Framework→Model
Đừng bắt đầu bằng câu hỏi: “GPT hay Claude? LangChain hay n8n? MCP hay framework nào?”
LỘ TRÌNH 7 CHẶNG

28 bài học từ tư duy đến production

01

Tư duy nền tảng

Hiểu Agent thực chất là gì trước khi viết code.

Bài 1. AI Agent không phải chatbot

Phân biệt Chatbot, LLM App, LLM + Tools, Workflow, Agent và Multi-Agent. Hiểu khi nào không nên dùng agent.

WORKFLOW = code quyết định đường đi • AGENT = model quyết định đường đi

Bài 2. Goal → Task → Action

Phân rã mục tiêu thành task, subtask, action và tool. Thiết kế công việc trước khi chọn công nghệ.

Bài 3. Deterministic vs Probabilistic

Việc chắc chắn dùng code; việc cần hiểu, phân loại, lập kế hoạch và ra quyết định mới giao cho LLM.

Bài 4. Kiến trúc cơ bản của Agent

Nắm vòng lặp Observe → Reason → Act → Observe, cùng Model, State, Tools và Environment.

Mini project 1: Thiết kế trên giấy một Agent sắp xếp thư mục Downloads — chưa dùng framework.
02

Workflow Design

Biết thiết kế luồng xử lý trước khi biến nó thành agent.

Bài 5. Prompt Chaining

Ghép nhiều bước LLM theo chuỗi: Transcript → Clean → Summary → Social Content.

Bài 6. Routing

Phân loại input/intent và điều phối sang đúng nhánh xử lý.

Bài 7. Parallelization

Chạy đồng thời các tác vụ độc lập, sau đó tổng hợp kết quả.

Bài 8. Orchestrator–Worker

Một orchestrator phân rã việc và giao cho các worker chuyên biệt.

Bài 9. Evaluator–Optimizer

Generate → Evaluate → Pass/Fail → Improve → Evaluate. Nền tảng để agent tự sửa kết quả.

Mini project 2: Thiết kế workflow Transcript Zoom → biên tập → tóm tắt → mô tả YouTube.
03

Tools

Cho agent khả năng tác động lên thế giới thật một cách rõ ràng và kiểm soát được.

Bài 10. Function Calling

LLM chọn tool → code thực thi → tool result quay về LLM → agent quyết định bước tiếp theo.

Bài 11. Tool Design

Tool tốt phải có tên rõ, input rõ, output rõ, phạm vi rõ, lỗi rõ. Tránh “do_everything()”.

Bài 12. Tool Router

Dạy agent WHEN to use, WHEN NOT to use và WHAT arguments cho từng tool.

Bài 13. MCP

Hiểu MCP là chuẩn giao tiếp giúp model truy cập tools/resources — không phải bản thân agent.

Mini project 3: Python agent kiểm tra video: metadata, resolution, audio và đưa nhận xét bằng LLM.
04

Context, State & Memory

Quản trị đúng thông tin mà agent được nhìn thấy và ghi nhớ.

Bài 14. Context Engineering

Context gồm system instruction, user request, state, tool result, files, memory, examples và history.

Bài 15. Context Window

Token budget, overflow, compression, selective retrieval và summarization.

Bài 16. State

Biết agent đang ở đâu trong tiến trình: task, step, file hiện tại, những gì đã hoàn tất.

Bài 17. Memory

Phân biệt Working, Session, Long-term, Semantic và Procedural Memory.

Bài 18. Filesystem as Memory

Với agent local, filesystem + Markdown/JSON thường minh bạch và dễ debug hơn vector DB.

Mini project 4: Agent nhận task → lưu state → dừng → mở lại → tiếp tục công việc.
05

Agent Loop

Bây giờ mới thực sự xây một agent có khả năng tự quyết định bước tiếp theo.

Bài 19. ReAct Pattern

Reason → Act → Observe → Reason. Gắn suy luận với hành động và quan sát thực tế.

Bài 20. Planning

So sánh Plan-first với Dynamic Planning và chọn mức tự trị phù hợp.

Bài 21. Stopping Conditions

Task complete, max steps, max cost, timeout, human required — agent phải biết khi nào dừng.

Bài 22. Error Recovery

Retry, alternative tool, rollback, ask human hoặc stop khi API/tool/output thất bại.

06

Reliability & Safety

Đưa agent từ demo sang hệ thống có thể tin cậy.

Bài 23. Guardrails

Input guardrail → Agent → Tool permission → Environment → Output validation.

Bài 24. Human in the Loop

GREEN: tự làm • YELLOW: làm và ghi log • RED: phải xin phép.

Bài 25. Sandboxing

Kiểm soát quyền run shell, Python, filesystem và web để giới hạn thiệt hại khi agent sai.

Bài 26. Evaluation

Đo success rate, tool success, task completion, latency, token cost và retry rate bằng test cases thật.

07

Framework & Production

Chỉ học framework sau khi đã hiểu bản chất kiến trúc.

Bài 27. Framework

Thứ tự đề xuất: Python + raw API → OpenAI Agents SDK → LangGraph → Google ADK.

Bài 28. Multi-Agent

Chỉ dùng khi single-agent + tools không còn đủ. Nhiều lúc 1 agent + 5 tools tốt hơn 5 agents.
